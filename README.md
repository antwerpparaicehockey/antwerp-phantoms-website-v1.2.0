# Antwerp Phantoms Website v1.2.0

## Permanent GitHub content workflow

This build can be opened and edited locally. Settings changes are temporarily kept in browser storage while you work.

When the content is ready:

1. Open `settings.html` and log in.
2. Complete and test all content.
3. Open **Publish**.
4. Click **Download publication file**.
5. Replace the existing `published-data.js` in this folder with the downloaded file.
6. Open `index.html` locally and verify the website.
7. Copy/push the complete folder to GitHub Pages.

The online website reads its permanent starting content from `published-data.js`. Therefore published texts, images, documents, sponsors and albums remain available after browser history or local storage is cleared.

An editable JSON backup can also be downloaded and restored from the Publish panel.

## Security note

The local Settings password protects casual access only. A fully public GitHub Pages site exposes all client-side code, so this is not equivalent to server-side authentication. Permanent online editing requires a CMS or backend in a later version.
